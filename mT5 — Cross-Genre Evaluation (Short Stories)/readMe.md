# mT5 — Cross-Genre Evaluation (Short Stories)

##  Overview

This module evaluates mT5 on **short story data** to test cross-genre generalization.

---

## Objective

Assess robustness of the model trained on newspaper data when applied to:

* Narrative text
* Different stylistic structures

---

##  Model

* mT5 (trained on newspaper domain)

---

##  Data

* Short story dataset 

##  Evaluation

* BLEU score
* Exact Match Accuracy

---

##  Key Insight

mT5 maintains strong performance across genres, demonstrating:

* Robust contextual modeling
* Generalization beyond training domain
